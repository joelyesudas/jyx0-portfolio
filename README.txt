Apply to your existing project:
1. Back up your current src/App.jsx and src/App.css.
2. Copy these new src/App.jsx and src/App.css over the corresponding files in your project.
3. Copy public/images/joel.png to your project's public/images/joel.png.
4. Copy public/resume.pdf to your project's public/resume.pdf.
5. Keep your existing src/main.jsx if it already imports './index.css' and renders <App />. Otherwise, use the included src/main.jsx.
6. Run `npm run dev` from the project folder if the Vite server is not already running.
